# Package index

## Create documents

Helper functions to set up a new template directory with all required
files.

- [`create_rmd_doc()`](https://uham-bio.github.io/UHHformats/reference/create_rmd_doc.md)
  : Create a new directory with the R Markdown template
- [`create_quarto_doc()`](https://uham-bio.github.io/UHHformats/reference/create_quarto_doc.md)
  : Create a new directory with the Quarto template

## R Markdown output formats

Output format functions for use in the YAML header of `.Rmd` files.

- [`html_doc()`](https://uham-bio.github.io/UHHformats/reference/html_doc.md)
  : Convert to a simple HTML document
- [`pdf_doc()`](https://uham-bio.github.io/UHHformats/reference/pdf_doc.md)
  : Convert to simple PDF/LaTeX document in English (en)
- [`pdf_report()`](https://uham-bio.github.io/UHHformats/reference/pdf_report.md)
  : Convert to report-like PDF/LaTeX document in English (default) or
  German
- [`pdf_cheatsheet()`](https://uham-bio.github.io/UHHformats/reference/pdf_cheatsheet.md)
  : Convert to cheat sheet
- [`word_doc()`](https://uham-bio.github.io/UHHformats/reference/word_doc.md)
  : Convert R Markdown to a Microsoft Word document
